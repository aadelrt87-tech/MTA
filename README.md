# MTA
A beta version of the app is currently being tested.

## نسخة التطوير
- `index.html`: نسخة Neon التي راجعناها؛ منطق JavaScript والحقول مطابقان للنسخة المصححة.
- `DEVELOPMENT.md`: مراحل التطوير المقترحة.
- نقطة البداية: نسخة Neon قبل إضافة تبويب الإدارة أو المخازن أو التقارير.

## تشغيل GitHub Pages
من Settings → Pages اختر:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
ثم Save.

الرابط المتوقع بعد نجاح النشر: https://aadelrt87-tech.github.io/MTA/

## اتصال البيانات
هذه نسخة مستقلة من الواجهة فقط. رابط Apps Script الموجود في الكود ما زال رابط التطبيق الحالي؛ وبالتالي الحفظ يكتب في بياناته الحالية.
تجارب الحفظ تحتاج أولاً ربط نسخة Apps Script وشيت منفصلين، أو تنفيذ ترحيل تجريبي مستقل إلى قاعدة البيانات الجديدة.
